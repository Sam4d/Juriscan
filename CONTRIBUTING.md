# Contributing

Use Linux, Node 24.19.0 and pnpm 12.14.0. Run `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm format:check` and `pnpm smoke`. Keep scanners deterministic, read-only, bounded, and free of network/project execution. Strict TypeScript and versioned schemas are required.

A detector change needs a real syntactic/semantic signal, precise limitations, safe evidence, remediation acceptance criteria, and positive/negative/ambiguous fixtures. Test redaction and resource behavior. A missing feature must remain documented as missing, never represented by a tool that pretends to have performed it.

Legal-source changes require exact primary authority, version/sections, licensing, dates, applicability conditions, review ownership and court-status checks. Follow [source governance](docs/rules-and-sources.md). Retrieval success alone does not approve a legal rule. Do not submit copied legal text without redistribution rights.

Use minimal synthetic examples in issues. Security issues belong in a private channel described in [SECURITY](SECURITY.md). Do not introduce telemetry, source upload, arbitrary execution, deployment or destructive remediation without a separate threat model and explicit authorization design. Contributions are submitted under Apache-2.0 for original project code; third-party material must retain appropriate notices.
